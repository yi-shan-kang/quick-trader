三、核心投资策略

策略总框架：解决"择时"与"选股"两大难题

三姑自谦这套方法适合"水平低、反应慢、不追求高收益的人"。但其本质是用纪律化的资产配置替代择时，用机械化的轮动规则替代选股，将投资从"艺术"降维成"工程"。

A股权益 35%
海外权益 35%
债券收益 15%
黄金 15%

2026年最新四桶配置基准（权益合计70%，收益+黄金合计30%）

策略一：资产配置与动态平衡（解决"择时"）

  • 永远满仓：不择时、不空仓，"雷劈的时候要在场"
  • 7:3基准配比：权益类70% vs 收益类30%（早期为A股+债基，后期进化为四桶）
  • 2%动态调整阈值：当某类资产偏离基准超过2%时触发再平衡。权益涨到72%→卖出2%买入收益类；跌到68%→反向操作
  • 强制高抛低吸：用纪律替代预测，放弃对市场顶底判断
  • 四桶进化（2025年底）：A股35% + 美股35% + 债券15% + 黄金15%，同样以2%阈值动态调整

策略二：品种选择与平行换基（解决"选股"）

  • 主攻封基/定开基：利用封闭式基金的"折价"作为安全垫
  • 两条腿标准：净值增长（进攻的矛）+ 年化折价（防守的盾）
  • 四周轮入：买入看"近4周净值增长+年化折价"排名靠前者
  • 十周轮出：卖出看"近10周净值增长"持续恶化、排名靠后者
  • 弃弱留强：不需选最优基金，只需及时轮换掉最差的

四、封基选基方法论详解

1. 核心逻辑："遛狗理论"

基金净值是"主人"，交易价格是"狗"。狗虽然会跑前跑后，但最终一定会回到主人身边（封基到期时折价归零）。当"主人跑得快（净值增长快），狗跑得慢（价格没跟上，折价扩大）"时，就是绝佳买入机会。

2. 具体操作规则

维度买入标准卖出标准
观测周期 近4周净值增长 近10周净值增长
排名依据 4周净增 + 年化折价 综合排名靠前 4周和10周净增均弱 + 折价缩小 → 排名靠后
交易活跃度 需有足够成交量（流动性保障） 交易清淡时考虑轮出
核心原则 "弃弱留强"——不追求选最优，只求不持有最差

3. 工具：手工Excel跟踪

三姑不依赖任何高深软件，而是每个周末自己动手在Excel中记录：

基金净值 交易价格 折价率 4周净增 10周净增 综合排名

她强调："自己亲手做数据才能清楚前因后果，方便以后根据自身情况不断改良。"

七、投资方法论总结

1. 目标导向：以"跑赢年金"为锚

三姑的投资不是追求收益最大化，而是以6%年化收益率为目标（5000×12/100万=6%），对标商业年金产品。这个目标设定看似保守，实则精妙：

  • 6%选择面宽：可实现路径多，封基折价+债基+权益beta均可贡献
  • 12%选择面窄：只有少数高风险路径可走
  • 25%只能走钢丝：大概率不可持续

目标定得低，操作空间就大，心态就稳，这是知行合一的前提。

2. 四大核心原则

原则含义解决的问题
始终满仓 不择时、不空仓，"雷劈的时候要在场" 克服散户"想抄底逃顶"的执念
股债平衡 7:3配置+2%阈值动态再平衡 用纪律替代预测，强制高抛低吸
目标6% 不追求高收益，只跑赢年金产品 降低目标→拓宽路径→稳定心态
折价增强 买折价封基，持有到期赚折价收敛 不选牛基（差距仅5-8%），而是买打折

3. "弱者体系"的本质

三姑的整套方法本质上是一种弱者体系（借用冯柳的概念）：

  • 不靠精准选股 → 用基金工具替代个股
  • 不靠精准择时 → 用2%阈值机械再平衡
  • 不靠信息优势 → 用公开数据+Excel手工跟踪
  • 不靠高频交易 → 低频操作，周末复盘即可
  • 不靠超额认知 → 用折价结构赚确定性收益

核心理念：让普通人少犯错。复杂不是本事，长期不犯大错才是本事。

4. 知行合一的执行力

"她拿得住，不代表你拿得住。你先问自己要什么，是收益、睡眠，还是自由？"

三姑真正厉害的不是选了哪些基金，而是把长期权益暴露，装进了一个自己能长期执行的系统里。19年间经历2008金融危机、2011-2013阴跌、2015股灾、2016熔断、2018贸易战、2020疫情、2022-2023调整，始终满仓扛下来，几乎每月都有操作记录。

她还有一个保守型保底组合（每月取金生活用），主组合（激进型）才能拿得住拿得稳。双组合结构是其心态稳定的关键。

八、普通人的启示与注意事项

值得学习的

  • 长期权益思维：保持对权益资产的长期暴露，不因短期波动离场
  • 纪律化再平衡：用2%阈值机械操作，克服人性弱点
  • 折价思维：买有安全垫的品种，比选牛基更简单务实
  • 多资产分散：A股+美股+债券+黄金，降低单一市场风险
  • 闲钱投资：只有用闲钱，心态才不会崩
  • 手工做功课：自己建Excel跟踪数据，理解前因后果
不能简单照抄的：
  • 抄了70%权益，但没抄到她的耐心：同样70%权益，有人能拿10年，有人回撤8%就崩溃
  • 抄了基金代码，但没理解底层风险：封基折价、QDII溢价等结构性机会可能被抄没
  • 抄了历史收益，但没想过自己能否熬过回撤：如果A股和美股一起跌，组合回撤有多大？
  • 现金几乎为0：遇到极端机会或压力，缓冲极有限
  • 封基折价在收窄：三姑的策略一直在进化（封基→分级A→转债→海外→黄金），不能刻舟求剑

三姑给新手的核心建议

  1. 知其所以然：不要盲目"抄作业"，必须理解并认可策略背后的逻辑
  2. 自己动手做功课：用Excel建立数据跟踪表，每周末记录净值、价格、折价、净增并排序
  3. 坚持闲钱投资：投入的钱一定是短期内不急用的闲钱
  4. 放弃预测：认清普通人无法准确预测涨跌，设好纪律后像机器一样执行
  5. 得之坦然，失之淡然：只赚取规则内属于自己的那部分平均收益
