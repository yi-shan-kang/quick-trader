# 七星高照ETF轮动策略

## 策略概述

七星高照ETF轮动策略（作者：屌丝逆袭量化，来源：聚宽文章 [【策略分享】近1年5.4倍-七星高照ETF轮动策略](https://www.joinquant.com/post/67371)）是一种基于**加权线性回归动量**的ETF轮动策略。策略对 ETF 池中的每只标的做指数衰减加权线性回归，以 **年化收益率 × R²** 作为动量得分，每日选出趋势最强的一组 ETF 持有，并结合流动性、近3日大跌、高位放量、R² 趋势稳定性等多因子过滤，配合止损风控。

策略定位为**稳健防守型**：覆盖境外、商品、债券、国内四大类资产，多标的分散持有、低频轮动，天然抗震荡，适合追求「稳稳跑赢大盘」的普通投资者。

本实现为**优化版**（参考 `example/七星高照ETF轮动策略/七星高照_优化版.py`），针对原版做出四项核心改造：

| # | 改造项 | 原版 V5.0 | 优化版 | 目的 |
|---|--------|----------|--------|------|
| 1 | 持仓数量 | 1 只满仓 | 5 只等分仓位 | 降低集中度，避免单票黑天鹅重伤 |
| 2 | 动量周期 | 24 天 | 60 天 | 降低短期噪声敏感度 |
| 3 | 流动性过滤 | 无 | 日均成交额 ≥ 1 亿 | 清理低流动性标的 |
| 4 | QDII 溢价处理 | 二级市场价 | 基金净值计算动量 | 避免跨境ETF场内溢价干扰 |

## 策略逻辑

### 动量打分

对 ETF 池中每只 ETF，取近 60 日收盘价做**指数衰减加权线性回归**（半衰期 10 天，最新数据权重最高）：

```
slope          = 加权线性回归斜率
年化收益率     = e^(slope × 250) - 1
R²             = 加权判定系数（衡量趋势稳定性）
动量得分 score = 年化收益率 × R²
```

### 多因子过滤

| 过滤条件 | 参数 | 说明 |
|---------|------|------|
| 流动性 | `liquidity_min_amount=1e8` | 近 20 日日均成交额 < 1 亿元剔除 |
| 近3日大跌 | `loss=0.965` | 近 3 日单日跌幅 > 3.5% 剔除 |
| 高位放量 | `volume_threshold=2.5` | 量比 > 2.5 且年化收益 > 100% 剔除（仅非QDII） |
| R² 趋势稳定性 | `r2_min_threshold=0.4` | R² < 0.4 剔除（趋势不稳定） |
| 得分范围 | `min/max_score=0/5` | 得分必须落在 (0, 5) 区间 |

### 调仓规则

- **每日评估**：每个交易日计算全池动量排名，取前 5 只得分 > 0 的 ETF 为目标
- **等权配置**：每只目标 ETF 分配总资产的 1/5
- **防御补位**：合格标的不足 5 只时，用货币 ETF（511880 银华日利）补位，空仓即持现金等价物
- **调仓容差**：仓位偏离目标 5% 以内不调仓（`rebalance_threshold=0.05`），减少无效交易

### 风控

- **止损**：持仓相对成本价跌幅超过 8% 时卖出（`stop_loss=0.92`）。日线回测框架下每日开盘检查一次，近似原版的盘中每分钟止损。

## 使用方式

### 前置准备

策略回测依赖 ETF 历史行情。QMT 客户端连接时可自动下载；QMT 离线时需先用已有数据缓存初始化磁盘缓存：

```bash
# QMT 离线时：将 DATA/cache/etf_data_cache_qmt_10y.pkl 写入 QMT 磁盘缓存分片
.venv\Scripts\python.exe DATA\seed_etf_qmt_cache.py
```

### 运行回测

```bash
# 默认区间 2020-04-28 ~ 2026-04-28
.venv\Scripts\python.exe strategies\qixing_gaozhao_etf_strategy\run_qixing_gaozhao_backtest.py

# 指定区间
.venv\Scripts\python.exe strategies\qixing_gaozhao_etf_strategy\run_qixing_gaozhao_backtest.py 2016-01-01 2025-12-31
```

也可通过主程序运行：

```bash
.venv\Scripts\python.exe main.py --mode backtest --strategy qixing_gaozhao --period 1d --start 2020-04-28 --end 2025-12-31 --debug
```

## 注意事项与限制

1. **QDII 净值**：跨境 ETF 存在场内溢价，原版使用基金净值计算动量；本项目回测数据源（QMT 行情）暂无基金净值接口，统一使用市场收盘价，结果会略受溢价扰动。
2. **止损粒度**：原版盘中每分钟止损，日线回测框架中改为每日开盘检查一次（近似实现），实际盘中止损更及时。
3. **数据覆盖**：部分 ETF 上市时间较晚（2021 年后），在早期回测区间无数据会被跳过；若需精确还原早期表现，需补齐对应标的的上市前区间数据或调整回测起点。
4. **T+0 处理**：ETF 均按 T+0 处理（`set_t_plus_1=False`）。
5. **并非高枕无忧**：七星策略牛市跑得快（强于年化 15-25% 的普通策略），但熊市/震荡市回撤较大（原版单标的版本在 2018/2022 年曾有 -28%~-42% 回撤），优化版多标的分散后显著改善。
