# 小市值策略优化提示词

## 任务目标
针对 `strategies/small_cap_strategy/small_cap_strategy.py`（配套说明见 `strategies/small_cap_strategy/readme.md`）实现的小市值策略，系统性提出 **10 项具体优化建议**。每项建议须包含：优化方向、技术实现路径、预期改进目标。对每项建议独立实施并回测验证。

## 回测口径（统一基线，所有优化对比均基于此）
```
对小市值策略进行回测：
- 调仓频率：按月轮动（月度调仓）
- 标的池：中证全指历史成分股（000985，含退市股，避免幸存者偏差）
- 选股规则：按总市值升序取最小的前20只，等权重配置
- 回测区间：2015-01-01 至 2025-12-31
```

## 基线指标
在未做任何优化的情况下，当前策略基线表现：
- **夏普比率：1.29**
- 年化收益：37.6%
- 最大回撤：-52.96%
- 总收益：+2857%（2015-2025，11年）

## 评价与筛选标准
1. 以**夏普比率**为核心衡量指标，同时关注最大回撤与年化收益
2. 每次优化须记录：优化前后完整指标对比（夏普、年化、最大回撤、总收益）+ 回测性能数据 + 可视化图表
3. 筛选规则：
   - **夏普比率提升 ≥ 5%** 的方案 → 保留并整合进最终策略
   - 未达预期或导致性能下降的方案 → 放弃，并在文档中记录具体原因与经验总结
4. 保存与版本管理：将每次优化的完整代码实现及对应回测结果保存至 `strategies/small_cap_strategy/optimization/` 下的独立目录，命名规范 `opt01_xxx/`、`opt02_xxx/`…，便于后续对比分析
5. 所有优化必须在统一基线口径下回测，禁止通过修改回测区间/股票池/选股数量来虚增收益

## 输出要求
完成后输出一份《优化报告.md》，包含：10 项优化方案总览表、每项优化详细分析（含代码实现、回测结果、保留/放弃结论及原因）、最终整合后的策略参数与完整回测结果。
