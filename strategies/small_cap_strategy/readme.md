# 小市值策略 — 纯市值排序 + 基础过滤 + 月历空仓

## 一、策略简介

小市值策略核心逻辑：A股市场长期存在规模溢价（Size Factor），市值最小的股票组合历史上取得过显著超额收益。策略按总市值升序选股，等权重持有，月度调仓。

## 二、选股流程

```
股票池(中证全指历史成分股) → 基础过滤 → 市值计算 → 市值上限过滤 → 按市值升序取前N只 → 等权持有
```

### 1. 基础过滤（手册口径）

| 条件 | 参数 | 默认值 |
|------|------|--------|
| 上市满1年 | `min_list_days` | 365 |
| 非ST/*ST | `exclude_st` | True |
| 非科创板(688)/北交所(8xx/4xx/920) | `exclude_kcb_bse` | True |
| 换仓日非涨停 | `exclude_limit_up` | True |

### 2. 市值计算与数据门禁

- 市值 = 总股本 × 当前股价，总股本 = 所有者权益合计 / 每股净资产（两者缺一不可）
- 价格异常（<1元）/ 停牌退市（>20自然日无行情）/ 股本数据缺失 → 剔除

### 3. 市值上限过滤

`max_market_cap`（默认30亿）：剔除壳资源炒作中的高市值小票，聚焦真正的小盘股。

### 4. 月历空仓

`skip_months`（默认1、4月）：小市值股票在1月（业绩预告暴雷）、4月（被ST高发）历史上平均收益为负，空仓避险。

## 三、回测结果（2015-2025，中证全指历史成分股）

| 指标 | 基线(20只) | 优化后(30只+上限30亿) |
|------|-----------|---------------------|
| 夏普比率 | 1.29 | **1.38** |
| 年化收益 | 37.6% | **41.4%** |
| 最大回撤 | -52.96% | **-51.64%** |
| 总收益 | +2857% | **+3847%** |

## 四、策略参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `rebalance_freq` | `'monthly'` | 月度调仓 |
| `max_stocks` | `30` | 最大持仓数 |
| `max_market_cap` | `30` | 市值上限（亿元） |
| `position_ratio` | `0.95` | 仓位比例 |
| `skip_months` | `(1, 4)` | 1月、4月空仓 |
| `max_stale_days` | `20` | 停牌/退市判定阈值 |

## 五、优化记录

完整优化报告见 [optimization/优化报告.md](optimization/优化报告.md)。

**采用**：市值上限30亿 + 持仓30只（夏普1.29→1.38，+6.3%）
**放弃**：波动率过滤/止损/动量过滤/ROE过滤/双周调仓/行业分散（2015-2025全指口径下夏普均未达基线+5%）

> 注意：优化结果强依赖回测区间与股票池。旧报告(2020-2026中证1000)中波动率过滤+止损有效，但换到2015-2025全指口径后失效，说明此类结论不可跨口径迁移。

## 六、风险提示

1. 注册制推行后小市值因子长期溢价可能收窄
2. 小盘股流动性差，实盘冲击成本高于回测
3. 任何历史回测都不能保证未来收益
4. 建议仓位占比10%~20%，最小资金4万元以上（持有20只为佳）
